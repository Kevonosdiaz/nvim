## Vim Stuff to Learn
| Keybinding | Action |
| ---------- | ------ |
| I | Edit at start of line (excl. whitespace) |
| ci(, ci" | \[C]hange \[I]n bracket/quote pair, etc. |
| \<C-a>, \<C-x> | Increment (++) and decrement (--) number |
| J | \[J]oin line with below line, separated by space |
| :vs | Alias for :vsplit command |
| :e! | Command to reset changes in buffer |
| :restart | Command to restart, preserving buffers/windows |

## LSP, Telescope, Mini, and Snacks

| ---------- | ------ |
| ga | Perform LSP code action |

| Keybinding | Action |
| ---------- | ------ |
| gR | Goto References |

| Keybinding | Action |
| ---------- | ------ |
| va) | Visual select around pair of () |
| vab | Same as above, but for any bracket type |
| vaq | Same as above, but for any quote type + backticks|
| t, f, a | Select tag pair (e.g XML, HTML), function call, or argument |
| sa) | Surround selected text with () (e.g. `saiw(` or `viWsa(` )`|
| sd) | Delete surrounding () |
| ]i, [i | Jump between prev/next \[I]ndent |
